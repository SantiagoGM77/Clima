# 🚀 Clima

es un proyecto en el que puedes revisar el clima en varios lugares de el mundo y sus caracteristicas mas destacadas , como la velocidad de el viento , la calidad y la humedad

## 🛠️ Tecnologías Utilizadas

- **Frontend:** HTML5, CSS , Javascript
- **Backend:** APIs OpenWeatherMap

## ✨ Características Principales

- Revisar Clima Actual y Los dias Siguientes.
- Poder Consultar el Clima de Diferentes lugares
- Muestra Caracteristicas Relevantes de el Clima
